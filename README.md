## 🚀 Overview

VICI Studio is a digital studio platform built with React, TypeScript, Tailwind CSS, and Vite. It features interactive client portfolios, live interactive previews, deep-dive case study architecture breakdowns, service catalogs, and an administrative CRM dashboard.

## ✨ Key Features

- **🌐 Interactive Live Previews & Viewport Controls**: Real-time iframe and interactive viewport switching (Desktop, Tablet, Mobile) with quick copyable live deployment links.
- **📑 Deep-Dive Case Studies**: Structured breakdown of **The Problem**, **The Solution**, and **The Approach** for real-world client engagements.
- **🔒 Dedicated Admin Dashboard & CMS**:
  - Secure credential-based access (`/admin`)
  - Project portfolio editor & case study publisher
  - Client reviews & testimonials management
  - Service catalog & pricing management
  - Client CRM pipeline & enquiry tracking
- **💬 Direct WhatsApp & Lead Dispatch**: Integrated consultation workflows directing inquiries with pre-formatted WhatsApp briefs.
- **🎨 Responsive UI**: Built with modern design principles, fluid typography, subtle glassmorphism, and responsive modal alignments.

---

## 🛠️ Tech Stack

- **Framework**: React 18 / Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State Management**: React Context & LocalStorage Persistence

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:3000` to view the application in the browser.

### 3. Build for Production
```bash
npm run build
```
